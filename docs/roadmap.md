# Roadmap

## MVP

Secure ZIP and public GitHub import; Python AST scanning; file, symbol, and import map; source explorer; search; dependency cycles and basic impact; read-only Git metadata; local SQLite persistence; tests and project documentation.

## Next milestones

- Improve incremental analysis and progress cancellation.
- Add reliable, scope-aware Python call resolution and graph comparison between commits.
- Improve progressive loading, filtering, and performance for very large repositories.
- Add JavaScript/TypeScript parser adapters with measurable coverage.
- Add independently tested adapters for Java, C++, Go, and Rust.
- Explore native desktop folder opening and optional saved analysis export.
