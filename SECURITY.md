# Security Policy

Please do not report exploitable vulnerabilities in public issues. Send a private report to the repository maintainers with a concise description, impact, reproduction steps, and any safe proof of concept. Do not include another person's secrets or data.

CodeAtlas treats imported repositories as untrusted input. It must not execute imported code or install project dependencies. ZIP extraction, path handling, archive sizes, network URL validation, and Git inspection are security-sensitive. Please report vulnerabilities affecting these boundaries promptly. Until a private reporting address is configured, contact a maintainer through the hosting platform's private reporting feature.

No security-response time guarantee is made for this early MVP.
